# QuizMe — JavaScript Quiz App

An interactive quiz app built with vanilla JavaScript that tests knowledge of core JavaScript concepts — the same concepts it's built with.

## Live Demo
[View live](https://wwwrania1922-beep.github.io/quiz-app/)

## Built With
- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or libraries)

## Features
- 5 multiple-choice questions rendered dynamically from a JavaScript array
- Instant visual feedback — correct answers turn green, wrong picks turn red
- Live progress bar that updates as you move through the quiz
- Final score screen with a performance message
- "Try again" button that resets the quiz without reloading the page

## What I Practiced
- Storing structured data using arrays of objects
- Manipulating the DOM to build UI elements dynamically (no hardcoded HTML for questions)
- Handling click events and disabling buttons after an answer is selected
- Using conditional logic to check answers and calculate a score
- Writing functions that each handle one clear responsibility (loading a question, checking an answer, showing results, resetting the quiz)
